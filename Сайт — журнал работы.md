# Сайт ivangrigorenko.com — журнал работы

Рабочий журнал проекта. Веду по ходу, чтобы при обрыве контекста ничего не терялось.
Последнее обновление: 2026-10-02.

---

## Что это за проект

Копия сайта-портфолио Ивана, собранная на Next.js. Оригинал сделан в **Figma Sites**
и сейчас лежит на домене `ivangrigorenko.com`. **Цель — довести копию до полноценного
сайта и перевести домен на неё.**

- Прод копии: https://ivangrigorenko-site.vercel.app
- Репозиторий: `tank-dsgn/ivangrigorenko-site` (приватный), автодеплой по push в `main`
- Оригинал: https://ivangrigorenko.com

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind 4 · деплой Vercel.
Node лежит в `~/.local/node/bin` и не входит в PATH — перед командами:
`export PATH="$HOME/.local/node/bin:$PATH"`.

## Где брать исходные данные

**Figma MCP для этого сайта не работает.** Dev Mode MCP не читает файлы `figma.com/site/`
(проверено, Иван владелец — дело не в правах). Файл `figma.com/design/PcKsfvEhQUMve7PNQ3b6NC`
(«Site layouts») читается, но отдаёт такой же машинный вывод, архитектуру не улучшает.

**Рабочий источник** — выгрузка опубликованной страницы:

```
https://ivangrigorenko.com/_json/39c51217-69ff-4444-95d1-588378532cd6/<страница>.json
```

Английская главная лежит как `_index.json`. В выгрузке — настоящее дерево узлов Figma:
auto-layout, отступы, типографика, заливки, три брейкпоинт-фрейма (1280 / 800 / 375),
имена компонентов и переменных.

## Генератор вёрстки

`tools/figma/` — свой инструмент, переводит дерево Figma во flex-вёрстку.

```bash
node tools/figma/generate.mjs <страница> --json <путь> --sections
```

- `--sections` — режет страницу по секциям в `components/generated/<страница>/`
  с именами из макета и `index.tsx` как оглавлением. Так сделаны все 12 кейсов.
- `--keep-shell` — оставить шапку из макета (нужно только страницам меню).
- `tools/figma/optimize_assets.py` — PNG → WebP, карта подмен в `lib/asset-map.json`.

Главные и «Обо мне» написаны руками, контент в `lib/content/`.
Шапка и футер — ручные компоненты `Header` / `Footer`.

## ⚠️ Главная ловушка

**В выгрузке НЕ применяются переопределения инстансов компонентов** — приходит текст
мастер-компонента. Из-за этого уже были выкачены ошибки:

- английские страницы кейсов частично по-русски;
- кнопка «View case study» вместо «Посетить сайт»;
- на Mikulich подпись оказалась «Смотреть в контексте» со ссылкой в Instagram —
  **она своя у каждого кейса**, а у pot, ostral и vv кнопки нет вовсе.

Правки собраны в `tools/figma/overrides.json`:
`text.<язык>` + `pages.<страница>` (ключ — исходный текст макета) и `cards`.

**Как ловить такие ошибки.** Снять видимый текст с живого оригинала через браузер и
сравнить с отданным HTML копии. Делать это до показа Ивану, а не после.

## Как проверять точность

Высота каждой страницы должна совпадать с высотой фрейма из выгрузки. Проверка —
через iframe на локальном сервере, по трём брейкпоинтам (1440 / 900 / 390).
Сейчас расхождение 0…1px на всех 18 страницах.

## Страницы проектов — починены 02.10

Иван: «страницы проектов собраны очень плохо». Был прав. Проверка по высоте
страницы их пропускала: высота совпадала, а вёрстка внутри ломалась.
Сверка шла по координатам каждого элемента с оригиналом — нашлись четыре
ошибки генератора, все исправлены и выкачены.

| Что было сломано | Причина | Как чинилось |
|---|---|---|
| «Смотрите также»: 5 карточек в ряд, две за экраном | игнорировался `layoutWrap` и `counterAxisSpacing` | перенос строк во flex |
| Высокие скриншоты 536px вместо 1691px | 116 заливок в режиме `STRETCH`, кусок задаёт `imageTransform` | картинка отдельным тегом внутри обрезающего блока |
| Логотип в герое левее на 72px | игнорировались `constraints`: 403 узла привязаны к центру, 140 растягиваются, 23 к правому краю | привязки по горизонтали и вертикали |
| Стрелки высотой 3px (одна 0), знак Behance 32×32 вместо 32×20 | SVG тянулся по коробке узла, хотя обводка выходит за неё | ассет рисуется в своём размере и центрируется |

После правок: карточки 3 + 2, логотип героя 548,288 — точно как в оригинале,
стрелки 17×12, кнопка «Посетить сайт» 233,1640.

### ⚠️ Чем сверять дальше

**Высота страницы — плохой индикатор, она совпадала и при сломанной вёрстке.**
Сверять нужно координаты: собрать на оригинале и на копии список
`ключ|x,y,w,h` по всем картинкам, включая фоновые, и сравнить.

**Осторожно:** на порту 3000 может висеть старый сервер и отдавать прежнюю
сборку — перед проверкой `lsof -ti:3000 | xargs kill -9`, и `rm -rf .next`,
если правки не видны.

### Починено 03.10 — блок «Смотрите также»

Сверка `pot-ru` по координатам вскрыла главное: **в блоке показывались не те
проекты**. На странице POT в списке стоял сам POT, а Eazychange отсутствовал —
потому что карточки приходят из мастер-компонента, где исключён Eazychange.
То же было на всех страницах, кроме самой Eazychange.

Решение: состав блока теперь считается по странице — все проекты, кроме
текущего, в фиксированном порядке. Таблица подписей, картинок и размеров
лежит в `tools/figma/overrides.json` → `related` и `relatedOrder`.
Проверено: ни одна страница больше не ссылается сама на себя.

### Что осталось непроверенным

- Координаты сверены подробно на `eazychange-ru` и `pot-ru`. Остальные 10
  собраны тем же генератором и совпадают по высоте, но поэлементно не сверены.
- На `pot-ru` остались накопительные смещения по горизонтали внутри рядов
  (+66, +132 — похоже на разницу в расстоянии между элементами), пропавшие
  мелкие стрелки и узел `84f58ffc`, который в оригинале скрыт, а у меня виден.
- Мелкие расхождения на `eazychange-ru`: лишние буквы-векторы в секции логотипа
  (7 штук на y≈7819), элемент `409698ceac` которого нет в оригинале, узел
  `881dbfd60a` виден 35×35 вместо скрытого.
- Сверка текста по всем страницам — проверено 3 из 12.
- Скорость: тяжёлые страницы тянут до 142 картинок в трёх копиях под брейкпоинты.
